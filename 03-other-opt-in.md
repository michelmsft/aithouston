# Other Opt-In Methods

## AIT-Houston Mobile App and In-App Consent

In addition to website and SMS keyword opt-in, users may opt in through the AIT-Houston mobile application.

## Mobile App Opt-In Process

A user may provide consent during:

- New account registration
- Profile setup
- Notification settings update
- Phone number verification
- Event or donation-related communication setup

## How Consent Is Collected

The user enters their phone number and confirms consent through an in-app checkbox or notification preference setting.

## Example In-App Consent Text

By providing your phone number, you agree to receive SMS notifications from AIT-Houston and Mostofit LLC. Messages may include account verification, event reminders, announcements, donation confirmations, and urgent community updates. Message and data rates may apply. Reply STOP to unsubscribe or HELP for help.

## OTP / Verification Code Use

When phone verification is required, the user receives a one-time passcode by SMS after entering their phone number in the app.

Example message:

Your AIT-Houston verification code is 123456. This code expires shortly. Do not share it with anyone. Reply STOP to unsubscribe or HELP for help.

## Opt-Out

Users can opt out at any time by replying **STOP**.

## Help

Users can reply **HELP** to receive support instructions.
